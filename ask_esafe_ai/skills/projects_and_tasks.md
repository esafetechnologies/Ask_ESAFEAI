# Projects and Tasks

Use this skill when a user asks about ERPNext Projects, task assignments, deadlines, status, or progress.

## Review and update work

- Identify the exact Project or Task. If multiple records match, show their IDs and ask the user to choose.
- Read only records visible to the current user. Summarize status, assignees, dates, dependencies, and progress using the values stored in ERPNext.
- Call out overdue dates based on the current date and distinguish completed work from open work.
- For requested changes, check the document metadata and permissions, prepare a proposal for the exact fields being changed, and wait for explicit confirmation before applying it.
- Never silently reassign a task, change a deadline, mark work complete, or create a project or task.
