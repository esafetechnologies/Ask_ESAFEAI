# Customer Account Summary

Use this skill when a user asks about a customer's account, outstanding balance, invoices, or payment history.

## Work safely

- Confirm the customer using an exact name, ID, or phone number. If more than one customer matches, show the matches and ask which one they mean.
- Read only Customer, Sales Invoice, Payment Entry, and related records that the current user is permitted to access.
- State the date or period covered by every summary. Distinguish submitted invoices, outstanding amounts, overdue amounts, and payments received.
- Do not treat draft, cancelled, or returned documents as current receivables. Explain any exclusions.
- Never invent a balance or promise that a payment has cleared. Show the source record IDs so the user can verify the figures.
- For a request to create or change an invoice, payment, credit limit, or customer record, prepare a proposal using the normal permission-checked ERPNext tools and wait for explicit confirmation.
